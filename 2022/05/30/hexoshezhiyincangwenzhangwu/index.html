hexo设置隐藏文章（雾）

如若yuein · 2022-5-30 · 本文共 次阅读 · 字数统计: 432字 · 阅读时长≈ 1分钟

Author

如若yuein

你好呀

目录

    　　这是若儿突发奇想试出的方法，能够很好的把文章在列表里“隐藏”，虽然有亿点点费事，但至少有用，诶嘿！

    网上的做法

    　　首先还是先看看其他大佬的方法吧，挺简单的，只是部署的时候不太好看……

    安装hexo-generator-index2

    　　使用git bush 输入

    $ npm install hexo-generator-index2 --save
$ npm uninstall hexo-generator-index --save

    修改hexo配置文件

    　　打开博客根目录（非主题目录）下的_config.yml，添加：

    # index2 generator是否包含官方的hexo-generator-index，默认true（包含）
index2_include_index: true
index2_generator:
per_page: 8
order_by: -date # 按发布时间排序
exclude:
- tag hide # 不包含标签为hide的文章
- category hide # 不包含分类为hide的文章

    原文链接：（http://blog.fiftykg.com/hexo/hexo “首页隐藏部分文章.html”）

    若儿的尝试

    　　对于一般的hexo博客来说，文章都是post页面，而其他页面都是page，所以文章列表里只会放置在_post里的文章，相信看到这里大家都明白若儿要怎么做了。

    　　首先 hexo new page ‘name’，并在文章起头（index.md）处添加一个判断‘judgement’。由于渲染page时会走/layout/page.ejs（没有的话自己找找）：

    <%- partial('_partial/_page', {post: page, index: false}) %>

    所以只需将其改为

    <% if (page.judgement) { %>
    <%- partial('_partial/_post', {post: page, index: false}) %>
<% } else { %>
    <%- partial('_partial/_page', {post: page, index: false}) %>
<% } %>

    即可，可以发现当‘judgement’判断为true时，渲染走post，即文章模式，这样就创建了一个page的文章页面，文章列表是检测不到的，这就完成了“隐藏”。

    　　可以参考小站的阅览指南。
